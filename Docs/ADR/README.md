# Architecture Decision Records (ADR)

Architektur-Entscheidungen für das PoolSolarSystem Projekt.

## Über ADRs

Architecture Decision Records dokumentieren die wichtigsten Architekturentscheidungen und deren Begründungen.

Jede Entscheidung wird in einem separaten Dokument festgehalten und enthält:
- **Status**: Vorgeschlagen, Akzeptiert, Veraltet, Ersetzt
- **Kontext**: Situation und Problem
- **Entscheidung**: Was wurde entschieden
- **Konsequenzen**: Auswirkungen der Entscheidung
