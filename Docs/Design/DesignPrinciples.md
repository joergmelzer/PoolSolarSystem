# PoolSolarSystem Design Principles

## Ziele

- Einfach nachzubauen
- Open Source
- Modular
- Ohne Spezialwerkzeug
- Möglichst ohne Kaufteile
- Wartungsfreundlich
- Erweiterbar

## Druck

Standardmaterial:
PETG

Optional:
ASA

## Konstruktion

- möglichst ohne Stützmaterial
- Wandstärke ca. 3 mm
- große Radien
- robuste Konstruktion
