# Firmware

Mikrocontroller-Firmware für das PoolSolarSystem.

Dieses Verzeichnis enthält den Code für die Steuerung und Überwachung des Pools.

## Unterverzeichnisse

- **src/** - Quellcode-Dateien
- **include/** - Header-Dateien und Definitionen
- **lib/** - Externe Bibliotheken und Dependencies
- **data/** - Konfigurationsdateien und Daten
